# kvSorts
Análise de dados para empréstimos

Programa desenvolvido para definir se um cliente é bom pagador ou não com base em análise de dados modelados utilizado k-vizinhos mais próximos e vetores de distância

-> Como compilar o programa?

    Nota do autor:  o programa tem um executável com todos os módulos, basta executá-lo e o programa será iniciado
    
    Abaixo está o processo de compilação, caso o programa não possa ser executado

    1. Abra o terminal
    2. Navegue até o diretório kvSorts
    3. Insira no terminal o comando: gcc index.c coleta.c sort.c -o index.exe -lm
    4. Insira no terminal o comando: ./index.exe

    O programa será compilado.
